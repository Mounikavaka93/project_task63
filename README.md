# Vireo Sports Club

A responsive sports club site built with React, Vite, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://127.0.0.1:5173). Pages: Home, About, Sports, Membership, Coaches, Events, and Contact.

```bash
npm run lint
npm run build
```
